HOW TO RUN — Quiz Generator & Evaluator
========================================

Input files live in the `input/` folder:
  - input/question_bank.xlsx      (70 questions: 12 Hard, 30 Medium, 28 Easy)
  - input/question_bank_72.xlsx   (72 questions: 12 Hard, 30 Medium, 30 Easy)

A question bank Excel must have these columns:
  question_no, question, option_a, option_b, option_c, option_d, answer (A/B/C/D), difficulty (H/M/L)

Question paper sets are labelled S-01, S-02, ... Use those exact strings for the
"Question Set" dropdown in the Google Form so responses join back to the answer key.

The student responses file is the Google Forms export, with columns:
  Timestamp, Email address, Full Name, Roll Number, Question Set,
  Q - 01 [Answer], Q - 02 [Answer], ...   (one per question bank number)


1. SETUP (do this once)
-----------------------
  pip install -r requirements.txt


2. WEB APP — REFLEX UI (recommended)
------------------------------------
  reflex run

  Then open http://localhost:3000
  - "Generate Papers" page: upload a bank from input/, configure, download question_papers.xlsx
  - "Evaluate Answers" page: generate dummy responses (a stand-in for a real Google
    Forms download), then check & score, download scoring_report.xlsx
    Sheets: Scores, Summary, Validation, Faculty_Report, Responses_Review


3. WEB APP — STREAMLIT UI (original)
------------------------------------
  streamlit run app.py

  Same two-part flow as the Reflex app, in a two-tab layout.


4. COMMAND LINE
---------------
  Generate question papers:
    python main.py --input input/question_bank.xlsx --students 50 --hard 4 --medium 6 --easy 5
    (add --seed 42 for a reproducible allocation; omit it for a fresh random run)

  Generate dummy student responses:
    python check_answers_main.py generate \
        --question-bank input/question_bank_72.xlsx \
        --question-papers output/question_papers.xlsx \
        --students 70 \
        --output output/student_responses.xlsx

  Check & score responses:
    python check_answers_main.py check \
        --question-bank input/question_bank_72.xlsx \
        --question-papers output/question_papers.xlsx \
        --responses output/student_responses.xlsx \
        --output output/scoring_report.xlsx


5. TESTS
--------
  pytest -q


6. DEPLOYMENT (REFLEX CLOUD)
-----------------------------
  Live app: https://quiz-web-silver-moon.reflex.run

  To push updates:
    reflex login    (one-time, opens a browser to authenticate)
    reflex deploy --app-name quiz-web --project 67b7e9f1-6dba-4838-9eec-129ecd156331

  If `reflex deploy` prints only warnings and exits without deploying, the
  hosting CLI is out of date — it fails silently rather than reporting an error,
  so the cloud keeps serving the previous build. Fix:
    pip install --upgrade reflex-hosting-cli
  Check it worked with `reflex cloud project list`, which should print a table.

  Free tier: 1 CPU / 1GB RAM, up to 5 deployments.
